# WEB DESIGNER — Interactive Website Design Showroom

A premium, single-page design showroom that lets clients explore **26 distinct website design directions** before deciding what kind of website they want.

## What it does

- Clients land on a cinematic **WEB DESIGNER** hero.
- As they scroll, they enter 26 different website design concepts — each one presented as a **realistic, finished website preview** inside a browser frame.
- A fixed progress rail shows the current `01 / 26` plus the active design name.
- At the end, clients choose a design direction and confirm it with **“I WANT THIS DESIGN.”**

## Design directions included

Portfolio · Apple / Product · 3D Interactive · Scroll Animation · Scroll-Driven Video · Cinematic · Creative Agency · Dark Luxury · Minimal · Bento Grid · Glassmorphism · Parallax · SaaS · E-commerce · Restaurant · Real Estate · Architecture · Photography · Fashion · Gaming · Event · Interactive Storytelling · Dashboard / Web App · 3D Product Configurator · AI Product · Experimental / Award-Winning

## Tech

- Vanilla HTML / CSS / JavaScript — no build step, no dependencies.
- Every website style is hand-built in code so each preview looks and feels genuinely different.
- Responsive layouts for phones, tablets, laptops, and desktops.
- Scroll-driven parallax, reveal transitions, animated previews, and a fixed design-progress indicator.

## Run locally

Open `index.html` directly, or serve the folder with any static server:

```bash
python3 -m http.server 4173
```
Then visit `http://localhost:4173`.
